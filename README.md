# AIF-C01_prep

A free self-study web app for the **AWS Certified AI Practitioner (AIF-C01)** exam, written for learners without a technical background.

- **Learn**: one lesson per exam task, built around Cairnway Outfitters, an invented online outdoor-gear retailer.
- **Check**: practice questions with explanations, a question bank, and a timed mock exam of 65 questions in 90 minutes.
- **Explore**: concept simulators, "which service?" drills, flashcards and optional walkthroughs in the AWS console.

The app is a static site with no backend and needs no AWS account. Progress stays in your browser, and you can export it to a file.

Live site: https://mhoffmann-wbs.github.io/AIF-C01_prep/

## Development

```bash
npm install
npm run dev       # local dev server
npm test          # tests
npm run build     # production build
```

The content follows the official [AIF-C01 exam guide](https://docs.aws.amazon.com/aws-certification/latest/ai-practitioner-01/ai-practitioner-01.html) (v1.2). Every question is written for this app.
